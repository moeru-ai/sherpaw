# @sherpaw/vad

A WebAssembly (WASM) wrapper for VAD (voice activity detection) with sherpa-onnx.

## Quick start

```ts
import { createVad, initVADModule } from '@sherpaw/vad'

const vadModule = await initVADModule()

const vad = createVad(vadModule, {
  sileroVad: {
    model: './silero_vad.onnx',
  },
  sampleRate: 16000,
  numThreads: 1,
  provider: 'cpu',
  debug: 0,
  bufferSizeInSeconds: 30,
})

vad.acceptWaveform(mySamples)
if (vad.isDetected()) {
  const segment = vad.front()
  console.log(segment.start, segment.samples.length)
  vad.pop()
}
```

## Notes

- The prebuilt files are generated by the native build in `sherpa-onnx/`:
  `packages/vad/src/prebuilt/vad.js` and `packages/vad/src/prebuilt/vad.wasm`.
- Follow the upstream VAD model guidance in
  `sherpa-onnx/upstream/wasm/vad/assets/README.md`.
